# Личный бюджет

Приложение для учёта личных финансов.

## Назначение

Приложение помогает пользователю видеть общую картину личных финансов,
фиксировать доходы и расходы, анализировать операции по категориям и следить
за соблюдением запланированных бюджетов.

Приложение предназначено для человека, который вручную ведёт учёт своих
доходов и расходов.

## Основные пользовательские сценарии

1. Открыть обзор, выбрать месяц и увидеть доходы, расходы и их разницу за период.
2. Перейти к операциям и найти нужные записи с помощью фильтров по периоду,
   типу операции и категории.
3. Из списка операций открыть форму, указать тип, положительную сумму,
   категорию и дату, сохранить запись и увидеть её в списке.
4. Открыть бюджеты, задать месячный лимит для категории и сравнить его
   с расходами по этой категории за тот же месяц.
5. Открыть настройки и переключить светлую или тёмную тему оформления.

## Планируемые экраны

| Экран          | Планируемый адрес   | Содержимое                                                             |
| -------------- | ------------------- | ---------------------------------------------------------------------- |
| Обзор          | `/`                 | Доходы, расходы, разница за выбранный месяц и последние операции       |
| Операции       | `/transactions`     | Список доходов и расходов, фильтры и переход к добавлению записи       |
| Новая операция | `/transactions/new` | Форма с типом, суммой, категорией, датой и необязательным комментарием |
| Бюджеты        | `/budgets`          | Месячные лимиты по категориям, фактические расходы и остаток лимита    |
| Настройки      | `/settings`         | Переключение темы оформления                                           |

Основные разделы будут доступны через общее меню. Форма новой операции
будет открываться из списка с возможностью сохранить запись или отменить ввод.

## Планируемая первая версия

- Интерфейс на React + TypeScript с готовой библиотекой UI-компонентов.
- Клиентская маршрутизация между экранами без полной перезагрузки страницы.
- Единое оформление и базовая адаптивность для компьютера и телефона.
- Демонстрационные данные и изменения в памяти приложения; после обновления
  страницы допускается возврат к исходным данным.
- Одна валюта — рубли; категории из заранее подготовленного списка.
- Общие данные для операций, обзора и бюджетов, чтобы суммы совпадали.

Первая версия будет работать на демонстрационных данных без backend и базы
данных. Регистрация, банковские интеграции и конвертация валют пока не
планируются.

## Технологический стек

Текущий frontend:

- React;
- TypeScript;
- Vite;
- Material UI (MUI) — готовые компоненты интерфейса, Emotion — их стилизация;
- React Router — клиентская маршрутизация.

Планируемый backend: Python + FastAPI, PostgreSQL + SQLAlchemy.
Контроль версий — Git.

## Запуск

Требуется Node.js, совместимый с установленной версией Vite
(вся информация в файлах `package.json` и `package-lock.json`).

```bash
npm install
npm run dev
```

Адрес приложения выводится в терминале после запуска
`http://localhost:5173/`.

## Проверка проекта

```bash
npm run lint
npm run build
```

## Статус проекта

Подготовлены общий макет с адаптивным меню и пять страниц-заготовок.
Добавлены переходы между разделами, переход к новой операции и обратно,
а также страница для неизвестного адреса. Активный раздел выделяется в меню.
Подключена Material UI: меню, кнопки переходов, заголовки и контейнеры страниц
используют общую светлую тему с зелёным акцентом. Отступы и расположение меню
адаптируются к ширине экрана. Формы и финансовые данные пока не добавлены.

Структура интерфейса:

- `src/App.tsx` — соответствие адресов страницам;
- `src/components/` — общий макет и оформление страниц-заготовок;
- `src/pages/` — страницы приложения.
- `src/theme.ts` — общие цвета, типографика и настройки компонентов Material UI.

Для ручной проверки откройте все разделы меню, перейдите из операций
к новой операции и обратно. Проверьте кнопки браузера «Назад» и «Вперёд»,
обновление страницы `/transactions` и неизвестный адрес, например `/дфлвыьлдвтфыдовтфыдвтфыфвываывщфррвщфыращфывтафыжвиажфыв`.
На узком экране меню должно переноситься без горизонтальной прокрутки.
